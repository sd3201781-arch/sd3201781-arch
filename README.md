**[▶ Cricket Hotseat Sprint — play now](https://sd3201781-arch.github.io/Culor-Blue-Z-/)**

A 2–6 player, pass-and-play, timing-based cricket batting arcade game. Swing as the ball reaches the green zone — nail it for a six, mistime it and you're bowled. Each player gets 6 balls and 3 wickets; the highest total wins. Runs entirely in the browser, no install needed.
